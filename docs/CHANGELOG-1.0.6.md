# 1.0.6 工具栏入口布局修正

Edge 实测发现，Plasmo 在自定义根容器内仍使用绝对定位的覆盖层。没有相对定位和明确尺寸的根容器不会占据工具栏空间，导出与漫游按钮会落到相同坐标，导致点击漫游触发导出。

为每个按钮预留独立的 32×32 像素布局空间，并将该容器设为定位参照；浮动降级入口保留各自位置。此次没有改变数据接口或增加权限。修复需要在 Edge 验证两个按钮的边界不重叠，并分别验证真实点击行为，不能只检查按钮存在或给样式值写断言。

1.0.5 已验证个人文档单文件导出，以及知识库首页与带子页面的父页面正文两文件批量导出。落盘 ZIP 和内部 DOCX 的完整性及 XML 结构均通过；尚未验证图片、复杂表格和全部文件类型的显示保真。设置页的三个根目录排除项保存并重新打开后保持选中，测试后已恢复原设置。1.0.6 的入口行为复验仍待加载新版后完成。
