# 1.0.5 下载链路修正

Edge 实测已确认插件入口和个人目录加载，但 1.0.4 的异步导出后没有取得可验证的落盘文件，不能将任务完成数当作下载通过。通知自动消失也使失败原因难以复查。

本版在加入 JSZip 前，将下载 Blob 转为 Uint8Array，避免依赖打包环境中的 FileReader 适配行为。完成后重新打开窗口，保留结果、错误和实际下载链接，由用户点击保存 ZIP 或结果清单。压缩失败会显示错误，不会展示无效 ZIP 链接。

新增直接把导出队列接入真实 JSZip、生成 Blob 后重新读取内容的回归测试；新增二进制读取失败统计以及结果组件链接和错误显示检查。共 52 项测试和类型检查通过。测试数据为合成数据，真实飞书下载仍需单独完成 Edge 验收；尚不能据此宣称所有文件类型和文档格式保真。
