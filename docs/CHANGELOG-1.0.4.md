# 1.0.4 变更与验证说明

本版重点是导出完整性和可核对的执行结果。知识库中有子页面的节点也会导出自身正文；文件和文件夹使用不同的目录树标识，避免父页面与目录相互覆盖。知识库根页面有正文时同样保留。

导出进度在文件完成处理后增加，成功数只在文件内容有效并加入压缩包后增加。创建任务失败、等待超时、下载为空、权限错误均记录为失败。部分成功与全部失败使用不同提示，用户可以仅重试失败文件，并下载结果清单。成功生成的 ZIP 附带 `_导出结果.json`。

漫游排除设置改为按目录标识和父子关系判断，包括所有子孙目录。同名目录或目录标识的末字符不会影响其他目录。设置界面只显示文件夹。

列表接口会根据响应中的 `last_label`、`next_page_token` 或 `next_cursor` 继续读取，重复游标和缺少游标会报错。目录读取失败时，保留其他已读取文档并明确显示“不完整”警告。所有来源均失败时不会写入一个成功的空缓存。

文档索引与排除设置按飞书域名和当前登录会话隔离。存储键使用会话值的 SHA-256，不保存原始会话 Cookie。会话在扫描或导出期间变化时停止使用旧索引。读取 Cookie 的后台路径不再把值写入日志。旧版全局缓存不会自动导入，避免跨账号沿用。

网络请求增加超时、临时网络故障和 HTTP 429/5xx 的有限重试。导出创建属于 POST 请求，不自动重复提交，避免响应丢失后重复创建任务。下载返回错误 JSON、登录 HTML 或空内容时不会伪装成正常文档。未知文档类型会明确报错。

压缩包路径会处理非法字符和目录穿越片段，同路径文件会自动编号，避免覆盖。重复选择同一个文档只处理一次。页面工具栏位置改变时，在文档页提供浮动入口。

验证基于 Node.js 26、pnpm 11 和项目锁定依赖。`pnpm test` 共 48 项通过，`pnpm typecheck` 通过，Edge Manifest V3 包构建通过。测试覆盖目录扫描、分页、父页面正文、失败统计、漫游过滤、会话隔离、并发和超时。ZIP 检查实际生成并重新读取压缩包，但文件内容和网络响应为测试数据，不代表已验证 Office 文件格式或飞书真实下载。

尚未完成真实飞书账号的浏览器端到端验证。飞书网页内部接口不属于稳定公开契约，分页字段的现网兼容性仍需实测。其中知识库节点的 `child_paging` 如果表明仍有未读取子页，目前会明确报“不完整”，不会猜测其未知游标格式。

导出任务仍运行在当前页面中，刷新、关闭页面会中断任务；大批量文件仍在内存中统一打包。本版没有新增任务恢复或分卷下载。
