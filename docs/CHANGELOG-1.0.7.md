# 1.0.7 页面导航后恢复入口

从 Wiki 内部进入云盘时，飞书会替换工具栏。1.0.6 的两个按钮布局和独立点击已通过实测，但绑定的旧工具栏被移除后，入口随之消失，刷新页面才能恢复。

本版持续观察页面节点变化。当工具栏更换时，移动原有入口容器并保留其中的界面状态；工具栏暂时不存在时，在文档页显示浮动入口，出现后再移回。每类入口共享同一个创建过程，避免重复挂载。

新增四项回归，覆盖并发获取不重复创建、工具栏替换保留原节点、延迟出现工具栏，以及离开和返回文档页的恢复。共 56 项测试、类型检查与 Edge 构建通过。

最终 Edge 验收通过：从 Wiki 内部进入云盘后无需刷新即可看到并使用两个入口，返回 Wiki 后入口仍正常。云盘页面实际导出一份 DOCX，由用户在浏览器下载面板确认保存；外层 ZIP、结果清单和内部 DOCX 的完整性及正文 XML 检查通过。浏览器的每次下载询问属于现有设置，本版不修改它。

已有实机证据包括：个人 DOCX 导出；知识库首页与带子页的父页面正文两文档打包；ZIP 和内部 DOCX 完整性及正文 XML；目录刷新；正常漫游；设置持久化；排除全部根目录后阻止漫游并提示原因。尚未验证全部文件类型、复杂 Office 内容保真和未知知识库子页分页，页面关闭恢复与大文件分卷尚未实现。
