## 2026-10-25：1.0.5 下载结果可验证性

- 用户安装后，Edge 页面出现导出和漫游入口；个人目录可读取。对最小样本文档的导出未获得可验证的本地 ZIP，因此暂不提交推送。
- 发现原回归测试先经假收集器转换 Blob，未覆盖生产队列直接连接 JSZip 的实际用法；原通知会自动消失，也不利于检查最终失败。
- 改为队列中显式读取二进制，持久显示结果及 ZIP/清单下载链接，压缩失败保留错误。
- 52 项测试全部通过，类型检查通过；浏览器下载复验待新版加载后完成。公开记录不包含真实文档标题、标识或正文。

## 2026-10-25：1.0.6 真实布局缺陷

- 1.0.5 下载已实机验证：个人文档 1 份和知识库文档 2 份均落盘，ZIP/内部 DOCX 完整性及正文 XML 通过，带子页的父页面正文保留。
- 下载此前等待的原因已明确：Edge 要求用户选择打开、另存为或保存；不是已证实的 ZIP 生成失败。
- 设置项保存和重新打开持久化通过，但继续点击漫游时触发导出。DOM 测量证实两按钮坐标完全相同；根容器宽高为 0，内部 Plasmo 覆盖层绝对定位到同一祖先。
- 修正根容器的相对定位、固定尺寸和布局占位；版本提升 1.0.6。临时排除设置已恢复为空。真实布局和漫游复验完成前仍不提交推送。
