# 开发踩坑记录

## Wiki 节点同时是正文和容器

不能把 has_child=true 的节点仅当作文件夹。父页正文和子页面都需要进入导出模型，并且目录树中的文件键与文件夹键需要区分。

## 失败值不能被当作完成成功

创建、轮询和下载可能失败。返回 null 或异常都必须计入失败；进度应按处理结束计算，不能使用已启动数量或待处理总数冒充成功数。

## 目录标识不是路径数组

排除设置保存的是 token 字符串。取字符串末项只会得到一个字符；应沿文件的 parentToken 及目录父链匹配排除集合，不能用路径子串猜测归属。

## 本地缓存要和登录会话绑定

固定的全局存储键会跨域名和账号复用。新索引按域名与会话摘要隔离；弹出窗口需从当前飞书标签页确定上下文，扫描完成前还需复核会话是否变化。

## 分页需要证明已经结束

has_more=true 时必须继续读取。缺少或重复游标应显示不完整，不能静默返回首批记录。未知的知识库子页分页格式应等待真实样本验证。

## 原生构建组件与 pnpm 配置

pnpm 11 会要求明确许可原生依赖构建。项目仅允许锁定工具链需要的 watcher、SWC、esbuild、lmdb、msgpackr-extract 和 sharp。变更此配置后应重新执行安装以更新依赖状态；只执行 rebuild 可能仍让后续脚本触发自动安装。

安装时使用自定义 store-dir 的开发环境需保持配置一致，避免自动安装尝试切换缓存并要求清理 node_modules。必要时可直接运行本项目 node_modules/.bin 中的编译器定位构建问题，不要修改系统级配置。

## 导出队列成功不等于 ZIP 生成或保存成功

真实集成测试应直接把生产队列接入 JSZip。如果测试先用假收集器收集 Blob，再在测试中转换为二进制，就可能掩盖生产输入类型的兼容问题。本版将转换放入生产队列，并测试真实 JSZip 生成和重读。

异步完成后调用合成点击，无法证明浏览器确实保存了文件。结果应保留真实下载链接，区分“已生成”与“已保存”；压缩错误和失败原因不能仅依靠会消失的通知。未取得浏览器下载及文件内容证据前，不能标为端到端通过。

Edge 的“文件需要注意”不一定代表安全拦截。本次实际下载面板要求打开、另存为或保存。应先读具体提示，不能把工具没有捕获下载事件认定为插件失败。

## Plasmo 自定义容器仍包含绝对定位覆盖层

只在工具栏插入空 div，内部按钮不一定参与布局。本次两个根容器为零尺寸，覆盖层均 absolute/top:0/left:0，两个按钮完全重叠。必须为根容器建立相对定位参照并预留宽高和 flex 空间，再用真实页面边界与点击验证。单次漫游成功不能排除挂载顺序变化后入口互相遮挡。

## 页面内部导航会替换挂载点

工具栏首次出现后就断开观察，只能处理初始加载，不能处理飞书的内部导航。应持续检查挂载点，移动并复用已挂载的入口；避免为同一入口重新创建多个容器或丢失界面状态。文档页的工具栏延迟出现、消失以及恢复，都要作为独立状态转换验证。

真实验收还会受到其他扩展影响。应区分业务失败、浏览器保存确认和自动化工具暂停，不应为取得通过结果而关闭安全保护或将工具超时写成产品缺陷。
